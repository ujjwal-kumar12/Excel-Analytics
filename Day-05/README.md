## Key Learnings

- Retrieve data from horizontal and vertical tables.
- Perform exact and approximate lookups.
- Use INDEX and MATCH together for flexible lookups.
- Handle missing lookup values using IFERROR or XLOOKUP's `if_not_found` argument.
- Use absolute references to keep lookup ranges fixed.
- Combine Data Validation dropdowns with lookup formulas.
