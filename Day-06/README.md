
# Day 06 - Excel Advanced Practice

This folder contains practical exercises completed while learning Excel for Data Analytics.

## Topics Covered

### 1. Conditional Formatting
- Highlight cells using Greater Than and Less Than rules.
- Identify duplicate values.
- Highlight Top 3 values.
- Apply Data Bars, Color Scales, and Icon Sets.
- Highlight entire rows using formula-based rules.
- Manage and clear formatting rules.

### 2. Macros
- Record and run macros.
- Assign keyboard shortcuts and buttons.
- Automatically format headers and columns.
- Sort salary data using a macro.
- Calculate total salary using SUM.
- Understand relative and absolute references in macros.

### 3. Pivot Tables
- Summarize sales by region and product.
- Filter and sort Pivot Table data.
- Count orders and calculate average sales.
- Apply value filters.
- Display percentages of the grand total.
- Calculate running totals.
- Refresh Pivot Tables after updating source data.

## Files Included

- Conditional Formatting Practice
- Macros Practice
- Pivot Table Practice

## Learning Outcome

Practiced Excel's advanced features for data formatting, task automation, and data summarization.
