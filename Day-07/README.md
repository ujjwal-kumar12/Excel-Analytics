
# Day 07 - Excel Slicers

This folder contains practical exercises completed while learning Slicers in Microsoft Excel for Data Analytics.

## Topic Covered: Slicers

- Insert Slicers into Pivot Tables.
- Filter data using Slicers.
- Select multiple items using a Slicer.
- Use Region and Product Slicers together.
- Clear individual Slicer filters.
- Change Slicer styles and button layouts.
- Customize Slicer settings and display headers.
- Connect multiple Pivot Tables using Report Connections.
- Control multiple Pivot Tables with a single Slicer.
- Test interactive filtering across multiple Pivot Tables.

## File Included

- `Slicers Practice.xlsx` - Contains the sales dataset, Pivot Tables, and Slicer exercises.

## Learning Outcome

Learned how to create interactive Excel reports using Slicers and control multiple Pivot Tables through connected filters.
