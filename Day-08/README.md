# Day 08 - Power Query

This folder contains practical exercises completed while learning Power Query in Microsoft Excel for Data Analytics.

## Topics Covered

- Import data from an Excel Table into Power Query.
- Remove extra spaces using Trim.
- Standardize text formatting.
- Remove duplicate rows.
- Change data types for dates and numeric columns.
- Handle missing values.
- Load cleaned data back into Excel.
- Refresh queries after source data changes.
- Add new records and refresh the query.
- Split customer names into First Name and Last Name.

## File Included

- `Day-08 Power Query Practice.xlsx` - Contains the source dataset, cleaned data, and Power Query transformations.

## Learning Outcome

Learned how to clean, transform, and refresh datasets using Power Query in Excel.
